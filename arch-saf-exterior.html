Project Overview

This project involves renovating and extending one of the private villas within a high-profile palace complex in Riyadh. The objective is to upgrade the villa’s existing infrastructure and interior while seamlessly integrating the new extension with the original architecture, preserving the traditional aesthetic of the palace while incorporating modern functionality and design.

My Role

I led the project's design development and documentation from concept to construction readiness.

My key responsibilities included:

  • Creating 3D visualizations to support concept development and gain client approval.
  • Preparing the full 2D drawing package, including layout plans, elevations, sections, and detailed drawings. using AutoCAD.
  • Developing woodwork and joinery details to ensure design precision and execution quality.
  • Managing communication and deliverables using MS Office for schedules and reports.

Software Used: AutoCAD, 3ds Max, V-Ray, Photoshop, MS Office
